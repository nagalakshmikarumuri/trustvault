Project Architectural Structure

TrustVault is structured in clean layers designed for maintainability and scalability:

config Spring beans & web/security configuration
controller HTTP REST APIs & Thymeleaf web endpoints
service Business logic & transaction management
repository Spring Data JPA database interfaces
entity Database models (Users, Documents, Permissions, Audit)
security Authentication & RBAC (ADMIN, OWNER, VIEWER)
dto Data Transfer Objects for request and response payloads
exception Custom exceptions & global error handling
